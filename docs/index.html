The Problem

Why Clearance exists

The Oct 1 Incident

A Seeker user reported SKR was unstaked and gone after using a dApp Store app. The replies were "recovery accounts" — scammers. Users sign stake-program instructions they cannot read, then get hunted.

Source: Public Seeker community reports, Oct 1 2026

The Clearance Solution

Clearance is not a wallet. It does not sit between the user and Seed Vault (MWA doesn't allow a third-party firewall). Clearance is the pre-sign review card and the post-sign verifiable receipt.

Architecture: Honest about MWA limitations

The Clearance App

Four screens. One mental model: this phone tells me the truth about my money. Try the full flow — connect, scan, review, sign, settle.

Demo Flow (3 minutes)

  1. 01. Scan Task QR
  2. 02. Capture Evidence (photo + SHA-256)

Action Record

interface Action {
  id: string;          // UUID
  taskId: string;
  recipient: string;
  mint: string;        // SKR mint address
  rawAmount: string;   // "1000000000"
  decimals: number;
  network: 'devnet' | 'mainnet-beta';
  status: ActionStatus;
}

Evidence Record

interface Evidence {
  actionId: string;
  photoPath: string;
  photoSha256: string;
  note: string;
  capturedAt: number;
  manifestSha256: string;
}

Receipt Record

interface Receipt {
  actionId: string;
  evidenceDigest: string;
  transactionSignature: string;
  settlementStatus: SettlementStatus;
  observedAt: number;
}
